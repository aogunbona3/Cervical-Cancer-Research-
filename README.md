# Cervical Cancer Screening: A Research Perspective on AI and Machine Learning
This research project explores how artificial intelligence (AI) and machine learning (ML) can enhance cervical cancer screening by automating Pap smear image analysis. 
Conducted as part of Northwestern University's MS in Data Science program, this paper reviews recent literature on medical imaging techniques and ML-based classification methods that improve early detection and diagnostic consistency.

## Key Focus Areas
- Explored segmentation techniques (K-means, Fuzzy C-means, Watershed)
- Reviewed classification models (SVM – 98.5%, KNN – 99.27%, CNN)
- Assessed clinical relevance and real-world impact based on existing research


## Deliverables
- `Cervical_Cancer_Research.pdf`: Final academic paper with structured analysis
- Summary of machine learning tools discussed (conceptual only)


## Tools Mentioned (Research Context Only)
- TensorFlow, PyTorch
- AI-based pathology software
- SVM, KNN, CNN (as used in studies)
